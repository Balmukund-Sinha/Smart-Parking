# Data directories

Only the small demonstration file in `sample/` is stored in Git.

- `raw/` is generated by `python scripts/generate_dataset.py`.
- `processed/` contains generated analytics CSVs plus Spark Bronze/Silver Parquet output.
- `sample/parking_events_sample.csv` is a compact, reviewable example suitable for GitHub.

After cloning the repository, recreate the local data and model with:

```powershell
python scripts\generate_dataset.py
python ml\train_model.py
```

Generated data can be large and is intentionally excluded by the root `.gitignore`.
