Defensible architectural decisions for external viva panels, academic review boards, and technical evaluators.

Defense Topic 01 Stream Consistency

Why Kafka + PySpark Structured Streaming?

Provides end-to-end fault tolerance and exactly-once processing semantics through write-ahead logs and Delta checkpointing. Decouples variable IoT sensor burst rates (up to 520 ev/s during stadium events) from cluster compute without backpressure dropped frames.

Guaranteed Semantics Exactly-Once via Offsets
Defense Topic 02 Data Structures

Why Bloom Filter in Driver Memory?

Space-efficient probabilistic structure that answers novelty queries in \(O(k)\) constant time with zero false negatives. Uses only 128 KB for 1 million keys. Drops 1,842 redundant vehicle vibration flutter pings before triggering expensive relational database locks.

Space Complexity 128 KB (1,048,576 bits)
Defense Topic 03 Lakehouse Tiering

Medallion Delta Lake Justification

Separates raw append-only Bronze telemetry from enriched Silver aggregates and Gold municipal KPI summaries. Snappy compression yields a 4.8x storage reduction, enabling high-performance historical OLAP partition queries over months of civic traffic data.

Storage Efficiency 4.8x Compaction Ratio
